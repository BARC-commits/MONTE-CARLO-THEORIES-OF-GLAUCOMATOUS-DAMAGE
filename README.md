# Monte Carlo Simulation: Integrated Mechanical, Vascular, and Glymphatic Theories of Glaucomatous Damage

This repository contains the complete Python implementation for a Monte Carlo simulation exploring the integrated impact of **mechanical**, **vascular**, and **glymphatic** mechanisms on intraocular pressure (IOP) thresholds and glaucoma classification.

> **Important Caveat:** All findings generated by this model are strictly internal. The model generates its own synthetic disease labels based on theoretical assumptions and arbitrary parameter weightings. Without external validation against clinical outcomes, these findings must **not** be interpreted as evidence for or against actual clinical practice.

---

## 📌 Key Features

* **Large-Scale Virtual Cohort:** Simulates $100,000$ virtual eyes incorporating realistic physiological and demographic parameters (Age, CCT, Corneal Hysteresis, Scleral Stiffness, LC Pore Diameter, Baseline IOP, MAP, and CSFP).
* **Multi-Theory Vulnerability Modeling:** Calculates component thresholds and vulnerability scores across three distinct pathological frameworks:
1. *Mechanical Vulnerability* (scleral stiffness, lamina cribrosa pore diameter, thin LC, family history)
2. *Vascular Vulnerability* (nocturnal hypotension, mean ocular perfusion pressure [OPP], sleep apnea, diabetes, hypertension)
3. *Glymphatic Vulnerability* (cerebrospinal fluid pressure [CSFP], sleep disturbances, glymphatic genetic variants)


* **Sensitivity Analysis:** Compares an **additive integrated threshold rule** across 5 arbitrary weight configurations against a weight-invariant **weakest-link rule**.
* **Global Sensitivity & Partial Correlations:** Evaluates exact analytical Sobol indices (Dirichlet prior on the simplex) and partial correlation coefficients to control for shared-input dependence (e.g., age, CSFP, sleep apnea).
* **Epidemiological Calibration Hook:** Includes a one-parameter grid search exploring the tension between uncalibrated simulation outputs and real-world population prevalence benchmarks (~3.5%).
* **Publication-Quality Visualizations:** Automatically generates and saves 6 high-resolution (300 DPI) figures.

## 🛠️ Requirements & Dependencies

To run the simulation, you will need Python 3.8 or higher along with the following scientific computing libraries:

* `numpy`
* `pandas`
* `matplotlib`
* `scipy`

You can install the required packages using `pip`:

```bash
pip install numpy pandas matplotlib scipy

```

## 🚀 Usage

Clone the repository and run the main Python script:

```bash
git clone https://github.com/your-username/glaucoma-monte-carlo-simulation.git
cd glaucoma-monte-carlo-simulation
python simulation.py

```

The script will execute the 100,000-eye simulation, output statistical summaries directly to your console, and save publication-quality figures locally.

## ⚠️ Model Limitations & Disclaimer

* **Arbitrary Weights & Parameters:** The weight configurations and physiological constants implemented in this model are exploratory and arbitrary. The primary value lies in demonstrating model sensitivity rather than establishing absolute biological truths.
* **Clipping Artifacts:** Component thresholds are artificially bounded between 5.0 mmHg and 40.0 mmHg. A component threshold resting precisely at the 5.0 mmHg floor represents a modeling artifact rather than a physiological observation.
* **No Clinical Utility:** The traditional 21 mmHg threshold and clinical disease labeling possess diagnostic utility that this theoretical simulation does not capture. Clinical decision-making should never be guided by unvalidated computational models.
